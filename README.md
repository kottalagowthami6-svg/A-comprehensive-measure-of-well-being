# A Comprehensive Measure of Well Being

## Project Overview
A Comprehensive Measure of Well Being is a project designed to assess an individual's overall well-being by analyzing factors such as sleep, stress, exercise, happiness, and social support.

## Problem Statement
People often face stress, poor sleep, and unhealthy lifestyles that affect their overall well-being. This project helps collect and analyze well-being data to provide useful insights.

## Key Features
- Well-being data collection
- Sleep and stress analysis
- Exercise tracking
- Happiness measurement
- Overall well-being score

## Dataset Information
The dataset includes:
- ID
- Age
- Gender
- Sleep Hours
- Exercise
- Stress Level
- Happiness Score
- Social Support
- Well-being Score
